reTerminal E1002 Briefing Flasher

Put the Muse Gadget firmware on a Seeed reTerminal E1002 from Chrome or Edge on a desktop computer, so Muse can show your family's morning briefing on it.

1

Your SDK token

Change Forget

Every gadget needs one to pair. Create it at gadgets.muse.ai and read the SDK terms. It never goes into the firmware file. After installing, this page sends it to the device over USB, the device keeps it through updates, and this browser remembers it on this computer only.

2

Install

  1. Plug the reTerminal into this computer with a USB-C data cable and switch it on.
  2. Click Connect & install and pick its port. It usually shows up as a USB Serial, CH340 or wchusbserial device.
  3. First install: accept Erase device. Flashing takes a couple of minutes.

You haven't entered your SDK token yet. You can install without it, but the reTerminal can't pair until it has one.

This browser has no Web Serial. Use Chrome or Edge on a desktop computer. Web Serial needs https (or localhost).

Keep this tab in front while installing. When it's done, close the installer dialog: the page then sends your token.

Can't connect? Hold BOOT, tap RESET, release BOOT, then try again. No port listed? The cable is probably charge-only. On Windows, install the WCH CH34x driver.

3

Pair with Muse

  1. Muse app → Settings → Devices → turn on Developer mode.
  2. Pick MuseGadget-Disp-XXXXXX and pair. Press the green button on top of the reTerminal when asked to confirm.
  3. Set up the briefing server and Muse skill: setup guide, step 5.
Already installed? Send your token again

For a reTerminal running firmware from this page. Pick its port when asked.
